Swordfish Windows 64-bit portable build
=======================================

Requirements
- Windows 10 or Windows 11, 64-bit

How to run
1. Unzip the entire folder.
2. Double-click Swordfish.exe.
3. The first launch starts the bundled Java service and may take a few seconds.

SmartScreen / "Unknown publisher"
This build is compiled from source and is not Microsoft-signed.
If Windows blocks it: More info -> Run anyway
or right-click the zip/exe -> Properties -> Unblock.

Data location
Projects, translation memories and glossaries default to:
%APPDATA%\Swordfish
